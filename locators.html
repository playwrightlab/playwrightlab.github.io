page.getByText()

Find elements by their text content — substring, exact, or regular expression.

Substring (default)

contains
text.spec.ts
await expect(page.getByText('Welcome back')).toBeVisible();
Live element

Welcome back, Sagar! You have 3 new messages.

Exact match

exact: true
text.spec.ts
await page.getByText('Delete', { exact: true }).click();
Live element Delete Delete all items (won't match)

Regular expression

regex
text.spec.ts
await expect(page.getByText(/\$\d+\.\d{2}/)).toHaveText('$49.99');
Live element $49.99

Filter a list by text

filter
text.spec.ts
await page.getByRole('listitem')
  .filter({ hasText: 'Premium' })
  .getByRole('button').click();
Live element

HTML Element ↔ ARIA Role Map

The definitive cheat-sheet: each HTML element, its correct implicit ARIA role, and how to reach it with getByRole().

HTML element Implicit ARIA role getByRole() usage & notes
Landmarks & sectioning
<header> banner Top-level page header. getByRole('banner').
<nav> navigation getByRole('navigation', { name: 'Primary' }).
<main> main One per page. getByRole('main').
<aside> complementary getByRole('complementary').
<footer> contentinfo Top-level footer. getByRole('contentinfo').
<section> region* Only when it has an accessible name (aria-label). getByRole('region', { name }).
<article> article getByRole('article').
<form> form* Role form only when named. getByRole('form', { name }).
Headings & text content
<h1>–<h6> heading getByRole('heading', { level: 1, name }).
<p> paragraph Usually targeted with getByText() instead.
<blockquote> blockquote getByRole('blockquote').
<ul>, <ol> list getByRole('list').
<li> listitem getByRole('listitem').
<dl> / <dt> / <dd> term / definition <dl> itself has no role; <dt>→term, <dd>→definition.
<a href> link getByRole('link', { name }). An <a> with no href has no role.
<strong> strong Rarely queried by role.
<em> emphasis Rarely queried by role.
<code> code getByRole('code').
<img alt> img getByRole('img', { name }) or getByAltText(). Empty alt="" → presentation.
<figure> figure getByRole('figure').
<hr> separator getByRole('separator').
Forms & interactive controls
<button> button getByRole('button', { name }).
<input type="text"> textbox Also email, tel, url map here — except password.
<input type="search"> searchbox getByRole('searchbox', { name }).
<input type="password"> no role Not exposed as textbox. Use getByLabel('Password').
<input type="number"> spinbutton getByRole('spinbutton', { name }).
<input type="checkbox"> checkbox getByRole('checkbox', { name, checked }).
<input type="radio"> radio getByRole('radio', { name }).
<input type="range"> slider getByRole('slider', { name }).
<input type="file"> no role Use setInputFiles() via getByLabel().
<textarea> textbox getByRole('textbox', { name }).
<select> combobox listbox when multiple or size>1. getByRole('combobox', { name }).
<option> option getByRole('option', { name }).
<optgroup> group getByRole('group').
<fieldset> group Named by its <legend>.
<label>, <legend> no role Provide accessible names for other controls.
<output> status Live region. getByRole('status').
<progress> progressbar getByRole('progressbar', { name }).
<meter> meter getByRole('meter', { name }).
Tables
<table> table grid when interactive. getByRole('table').
<caption> caption Names the table.
<thead>, <tbody>, <tfoot> rowgroup getByRole('rowgroup').
<tr> row getByRole('row', { name }).
<th scope="col"> columnheader getByRole('columnheader', { name }).
<th scope="row"> rowheader getByRole('rowheader', { name }).
<td> cell gridcell inside a grid. getByRole('cell').
Disclosure & dialog
<details> group Expandable container.
<summary> button getByRole('button', { name, expanded }).
<dialog> dialog getByRole('dialog', { name }).
ARIA-only roles (no native element — set with role="…")
role="tablist / tab / tabpanel" tab, tablist, tabpanel getByRole('tab', { name, selected }).
role="switch" switch getByRole('switch', { name, checked }).
role="menu / menubar / menuitem" menu, menuitem getByRole('menuitem', { name }).
role="alert / status / log" alert, status, log Live regions. getByRole('alert').
role="tooltip" tooltip getByRole('tooltip').
role="tree / treeitem" tree, treeitem getByRole('treeitem', { name, expanded }).
role="grid / gridcell" grid, gridcell Interactive data grids.

*Conditional role — applies only when the element is named or configured as noted. Common getByRole() options: name, exact, checked, pressed, selected, expanded, level, disabled.
